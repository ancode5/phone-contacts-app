# Этап 2 — зашифрованная база и базовая синхронизация

Эта версия превращает локальный справочник в первую рабочую облачную версию.

## Что уже реализовано

- вход через Яндекс ID по OAuth PKCE;
- единый зашифрованный файл `contacts-database.enc` в общей папке Яндекс Диска;
- шифрование AES-GCM, ключ получается из пароля через PBKDF2;
- пароль не отправляется Яндексу и не сохраняется в GitHub;
- локальная рабочая копия в Dexie/IndexedDB;
- слияние изменений по правилу «последнее изменение побеждает»;
- файл блокировки `sync-lock.json`, чтобы две записи не выполнялись одновременно;
- одна зашифрованная резервная копия в день в папке `backups`;
- новые поля контакта;
- стартовый список организаций;
- пользовательские группы;
- поиск, фильтры и сортировка;
- корзина на 90 дней;
- немедленная попытка синхронизации после изменения;
- сохранение несинхронизированных изменений локально при отсутствии сети.

## Что пока не входит в этап 2

- экспорт в Excel;
- массовое назначение групп;
- поиск и объединение дубликатов;
- управление списком разрешённых Яндекс-аккаунтов внутри приложения;
- полноценное холодное открытие PWA офлайн после полного закрытия браузера;
- восстановление забытого пароля шифрования;
- автоматическое удаление старых резервных копий;
- опубликованный адрес приложения.

Эти функции будут добавляться после проверки этапа 2 на тестовых контактах.

## Установка поверх текущего проекта

1. Остановите `npm run dev` сочетанием `Ctrl+C`.
2. Распакуйте patch-архив.
3. Скопируйте его содержимое в корень проекта и подтвердите замену файлов.
4. Убедитесь, что ваш `.env.local` содержит:

```env
VITE_YANDEX_CLIENT_ID=46564f36ea254c5da1a7717f0225a625
VITE_YANDEX_REDIRECT_URI=http://localhost:5173/auth/callback
VITE_YANDEX_DISK_FOLDER=Справочник контактов
```

5. Запустите:

```cmd
npm install
npm run typecheck
npm run dev
```

6. Откройте `http://localhost:5173/`.

## Первый запуск владельцем папки

Если файла `contacts-database.enc` ещё нет, приложение предложит создать облачную базу.

1. Придумайте общий пароль длиной не менее 10 символов.
2. Запишите его в надёжное место.
3. Нажмите «Создать базу».
4. Приложение включит в новую базу уже существующие локальные контакты и стартовый список организаций.

Потерянный пароль восстановить невозможно. Яндекс Диск хранит только зашифрованный файл.

## Вход второго пользователя

1. Второй пользователь должен иметь право редактирования общей папки.
2. Он входит через свой Яндекс-аккаунт.
3. Вводит тот же пароль справочника.
4. Приложение скачивает и расшифровывает общую базу.

## Тест этапа 2

Используйте только тестовые данные.

1. Владелец создаёт контакт и группу.
2. Второй пользователь открывает приложение и нажимает «Обновить».
3. Второй пользователь меняет контакт.
4. Владелец нажимает «Обновить» и видит изменение.
5. Отключите интернет, создайте тестовый контакт, затем включите интернет и нажмите «Обновить».
6. Проверьте папку `Справочник контактов/backups`.

## Выход

Кнопка «Выйти» удаляет OAuth-сессию и локальную расшифрованную копию с текущего устройства. Облачная база и резервные копии остаются на Яндекс Диске.
