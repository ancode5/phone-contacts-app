# Переход на приватное GitHub-хранилище

Патч заменяет хранение базы на Яндекс Диске на приватный GitHub-репозиторий.
Яндекс ID остаётся только для входа и имени пользователя.

## До установки патча

1. Запустите старую локальную версию на `http://localhost:5173`.
2. Откройте справочник привычным паролем.
3. Убедитесь, что нужные контакты видны и нет ожидающих отправки изменений.
4. Не очищайте данные сайта `localhost:5173`: локальная Dexie-копия нужна для миграции.

## 1. Создайте приватный репозиторий данных

На аккаунте `ancode5` создайте новый репозиторий:

- имя: `phone-contacts-data`;
- видимость: **Private**;
- включите **Add a README file**, чтобы сразу появилась ветка `main`;
- GitHub Pages для этого репозитория включать не нужно.

В нём будут находиться только:

```text
contacts-database.enc
backups/
```

## 2. Создайте fine-grained token

Откройте настройки GitHub:

`Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token`

Рекомендуемые настройки:

- Token name: `phone-contacts-data-access`;
- Expiration: выберите разумный срок и запишите дату;
- Resource owner: `ancode5`;
- Repository access: **Only select repositories**;
- выберите только `phone-contacts-data`;
- Repository permissions → **Contents: Read and write**;
- остальные разрешения не добавляйте.

Скопируйте токен сразу после создания. Не добавляйте его в `.env`, GitHub Actions,
исходный код, README или сообщения коммитов.

## 3. Установите патч

Распакуйте архив в корень проекта с объединением папок и заменой
`src/services/cloudSync.ts`. Затем дважды нажмите:

```text
APPLY-GITHUB-STORAGE-PATCH.cmd
```

Скрипт изменит `src/App.tsx`, выполнит typecheck и production build.

## 4. Перенесите существующую базу

1. Запустите `npm run dev`.
2. Откройте `http://localhost:5173` в том же браузере, где раньше работала локальная версия.
3. Войдите через Яндекс.
4. На экране GitHub-хранилища укажите:
   - владелец: `ancode5`;
   - репозиторий: `phone-contacts-data`;
   - ветка: `main`;
   - созданный fine-grained token.
5. На следующем экране приложение сообщит, что облачной базы нет.
6. Нажмите создание базы и введите **старый пароль справочника**.

Приложение возьмёт контакты из существующей локальной Dexie-копии и создаст в
приватном репозитории `contacts-database.enc`.

Проверьте на GitHub, что файл появился. Его содержимое должно выглядеть как
зашифрованный текст, а не как список контактов.

## 5. Опубликуйте обновление

```cmd
git status
git add -A
git commit -m "Move encrypted database storage to private GitHub repository"
git push origin feature/cloud-sync
```

Дождитесь зелёного запуска GitHub Actions. Затем откройте:

```text
https://ancode5.github.io/phone-contacts-app/
```

На каждом новом устройстве нужно один раз указать репозиторий и токен, затем
войти через Яндекс и ввести пароль справочника.

## Безопасность

Fine-grained token даёт право изменять содержимое выбранного приватного
репозитория. Не публикуйте и не отправляйте его в обычных чатах. Для коллег
передавайте токен отдельно и только доверенным людям.

Опция «Запомнить токен на этом устройстве» сохраняет его в локальном хранилище
браузера. На общем или чужом компьютере не включайте эту опцию. Явный выход из
приложения удаляет токен и локальную копию контактов с устройства.

При компрометации токена немедленно отзовите его в настройках GitHub и создайте
новый. Зашифрованная база и история коммитов останутся в приватном репозитории.

## Яндекс Диск

Старый `contacts-database.enc` на Яндекс Диске пока не удаляйте. Оставьте его как
страховочную копию до успешной проверки локальной версии, GitHub Pages и второго
устройства. После проверки можно отозвать у OAuth-приложения права на Яндекс Диск
и оставить только права Яндекс ID.
