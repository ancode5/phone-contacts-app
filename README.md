# Рабочий справочник контактов

React/TypeScript PWA для единой рабочей базы контактов нескольких доверенных пользователей.

## Архитектура этапа 2

- **Яндекс ID OAuth PKCE** — вход пользователей;
- **Яндекс Диск REST API** — общий зашифрованный файл базы;
- **Web Crypto API** — AES-GCM и PBKDF2;
- **Dexie / IndexedDB** — локальная копия и офлайн-изменения;
- **PWA** — установка приложения и кэширование интерфейса.

Контакты не хранятся в GitHub. Репозиторий содержит только код приложения.

## Поля контакта

- ФИО;
- рабочий и личный телефон;
- рабочий и личный email;
- место работы;
- структурное подразделение;
- должность;
- заметки;
- несколько групп;
- избранное;
- даты создания, изменения и удаления.

## Запуск

```bash
npm install
npm run typecheck
npm run dev
```

Локальный адрес: `http://localhost:5173/`.

Подробная инструкция этапа: [STAGE-2-INSTRUCTIONS.md](./STAGE-2-INSTRUCTIONS.md).

## Проверки

```bash
npm run typecheck
npm run lint
npm run build
npm run preview
```
