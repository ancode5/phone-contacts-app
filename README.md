# Справочник контактов

Веб-приложение для совместной работы с единой зашифрованной базой рабочих контактов.

Пользователь входит через Яндекс ID. Рабочая копия хранится локально в IndexedDB, а общий зашифрованный файл базы — в отдельном приватном репозитории GitHub. Пароль шифрования и открытые контакты в репозиторий исходного кода не передаются.

## Возможности

- вход через Яндекс ID;
- локальная работа через Dexie / IndexedDB;
- шифрование базы средствами Web Crypto API: AES-GCM и PBKDF2-SHA-256;
- хранение `contacts-database.enc` в приватном репозитории GitHub;
- синхронизация между компьютером и телефоном;
- автоматические зашифрованные резервные копии;
- поиск, фильтры, избранное и корзина;
- организации и пользовательские группы;
- экспорт контактов в настоящий файл `.xlsx`;
- адаптивный интерфейс и установка как PWA;
- публикация интерфейса через GitHub Pages.

## Архитектура

```text
Браузер пользователя
├── React + TypeScript
├── Dexie / IndexedDB — локальная рабочая копия
├── Web Crypto API — шифрование и расшифрование
├── Яндекс ID OAuth — вход пользователя
└── GitHub Contents API
    └── приватный репозиторий phone-contacts-data
        ├── contacts-database.enc
        └── backups/
```

В публичном репозитории `phone-contacts-app` находятся только исходный код и настройки сборки. Зашифрованная база хранится отдельно в приватном репозитории `phone-contacts-data`.

## Поля контакта

Карточка контакта может содержать:

- ФИО;
- рабочий и личный телефон;
- рабочий и личный email;
- организацию;
- структурное подразделение;
- должность;
- заметки;
- группы;
- признак «Избранное»;
- даты создания и изменения.

## Требования

- Node.js `20.19` или новее;
- npm;
- современный браузер с Web Crypto API и IndexedDB;
- приложение в кабинете Яндекс OAuth;
- приватный репозиторий GitHub для зашифрованной базы;
- fine-grained token с доступом только к репозиторию данных и разрешением `Contents: Read and write`.

## Локальная установка

```bash
git clone https://github.com/ancode5/phone-contacts-app.git
cd phone-contacts-app
git switch feature/cloud-sync
npm install
```

Создайте `.env.local` на основе `.env.example`:

```env
VITE_YANDEX_CLIENT_ID=публичный_client_id
VITE_YANDEX_REDIRECT_URI=http://localhost:5173/auth/callback
```

`Client Secret`, пароль базы и GitHub token нельзя добавлять в исходный код или `.env`.

## Яндекс OAuth

Разрешённые Redirect URI:

```text
http://localhost:5173/auth/callback
https://ancode5.github.io/phone-contacts-app/
```

Яндекс используется для входа пользователя. Доступ к Яндекс Диску приложению не требуется.

## Подключение базы

При первом запуске на устройстве укажите:

```text
Владелец: ancode5
Репозиторий: phone-contacts-data
Ветка: main
Токен: отдельный fine-grained token устройства
```

Токен должен быть ограничен репозиторием `phone-contacts-data` и разрешением `Contents: Read and write`.

После подключения введите общий пароль зашифрованной базы. Потерянный пароль восстановить невозможно.

## Синхронизация

Изменения сначала сохраняются в локальной базе устройства, затем отправляются в приватный репозиторий. Другие открытые устройства периодически проверяют наличие новой ревизии.

Это файловая синхронизация, а не серверная база данных реального времени. После изменения на другом устройстве может потребоваться дождаться очередной проверки или обновить страницу.

## Экспорт в Excel

Кнопка «Выгрузить в Excel» создаёт настоящий файл `.xlsx`:

- русские буквы сохраняются без проблем с кодировкой;
- телефоны записываются как текст и не теряют `+` или ведущие нули;
- заголовок закреплён;
- включён автофильтр;
- настроена ширина колонок и перенос длинных заметок.

Экспортированный файл содержит расшифрованные данные. Не добавляйте его в Git и не отправляйте посторонним.

## Безопасность

- включите двухфакторную авторизацию GitHub и Яндекса;
- используйте длинный уникальный пароль базы;
- создавайте отдельный токен для каждого устройства;
- не публикуйте токены, пароль и экспортированные контакты;
- при потере устройства отзовите его токен;
- храните отдельную резервную копию зашифрованного файла.

Абсолютной защиты от взлома не существует. Не храните в справочнике пароли, паспортные данные, медицинские сведения и другие данные, для которых требуется специализированная защищённая система.

## Публикация
