# 📇 Мой справочник контактов

Исправленная версия офлайн-приложения для управления личными и рабочими контактами. Данные хранятся локально в IndexedDB и не отправляются на сервер.

## Возможности

- добавление, редактирование и удаление контактов;
- имя, телефон, email, компания, заметки и теги;
- поиск по всем полям;
- избранные контакты;
- экспорт и импорт JSON-бэкапа;
- адаптивный интерфейс;
- PWA и офлайн-работа после первой загрузки production-сборки.

## Требования

- Node.js 20.19+ или Node.js 22.12+;
- npm 10+.

Рекомендуется Node.js 22. В проекте есть файл `.nvmrc`.

## Установка и запуск

```bash
git clone <адрес-репозитория>
cd phone-contacts-app
nvm use            # при наличии nvm
npm install
npm run dev
```

Vite покажет локальный адрес, обычно `http://localhost:5173`.

## Проверка production-сборки

```bash
npm run typecheck
npm run lint
npm run build
npm run preview
```

## Формат экспорта

Приложение создаёт JSON следующего вида:

```json
{
  "schemaVersion": 1,
  "exportedAt": "2026-07-16T12:00:00.000Z",
  "contacts": []
}
```

При импорте также поддерживается старый формат, в котором корнем файла является массив контактов.

## Что было исправлено

- все TypeScript-типы импортируются через `import type`;
- удалён недопустимый boolean-индекс `isFavorite` в IndexedDB;
- добавлена миграция Dexie с версии базы 1 на версию 2;
- импорт JSON валидируется и нормализует отсутствующие поля;
- `tags` всегда является массивом, поэтому карточки не падают после импорта;
- исправлена загрузка контактов и зависимости React hooks;
- добавлена регистрация service worker, manifest и иконки PWA;
- `base: './'` позволяет публиковать сборку в подпапке, включая GitHub Pages;
- добавлена проверка подходящей версии Node.js.

## Важно про локальные данные

IndexedDB привязана к адресу сайта. Контакты из `localhost` не появятся автоматически на другом домене. Перед переносом приложения сделайте экспорт JSON, затем импортируйте файл на новом адресе.
